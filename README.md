# project_p.l
research into designing a plasmid for pluerotus osteatus 
it uses logic gates and a backbone system to make the mushroom glow brighter than any other species when it fruits, also it contains URA3 in the backbone which is for when it is injected into the mushroom and it will filter out the glowing species long term as the host mushroom will be uracil deficient.

the research also utilises ai training on genomic databases and a whole lot of coding errors...
